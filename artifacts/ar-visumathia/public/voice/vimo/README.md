# Vimo Voice Files

Drop pre-recorded MP3 files here. The runtime resolves each phrase
to a slug (`/voice/vimo/{slug}.mp3`).

## How to record

1. Open https://www.freetts.com/ or https://play.ht/ (free tiers ok).
2. Pick a **child / kid female Indonesian** voice. Examples that work well:
   - FreeTTS: Bahasa Indonesia → choose a female voice and lower age.
   - Play.ht / Murf.ai: search for "child", "kid", or "young" voices.
   - ElevenLabs (paid): Lily, Domi, or any 8-12yr child voice cloned to id-ID.
3. Paste each phrase below, generate, save the MP3 with the matching slug.
4. Place files in this folder.

If a slug's MP3 is missing, the app silently falls back to the browser's
Web Speech API. It works either way — the MP3s just sound much better.
