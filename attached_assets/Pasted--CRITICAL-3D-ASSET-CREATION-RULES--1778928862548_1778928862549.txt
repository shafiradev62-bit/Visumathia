==================================================
CRITICAL 3D ASSET CREATION RULES
==================================================

The current 3D assets look incorrect because they resemble:
- primitive geometry
- Roblox-style placeholders
- Unity starter assets
- AI-generated toy geometry
- smooth rounded cubes
- fake stylized assets

THIS IS STRICTLY FORBIDDEN.

==================================================
NEVER CREATE ASSETS USING:
==================================================

- simple cubes
- capsules
- spheres
- cylinders
- bevelled primitives
- stretched geometry
- geometric abstraction
- shape-only props

Do NOT fake objects using primitive forms.

Every object must feel:
- intentionally designed
- sculpted
- handcrafted
- believable
- rich in detail
- emotionally appealing

==================================================
HOW PROFESSIONAL GAME ASSETS ARE BUILT
==================================================

Every prop must include:

1. PRIMARY FORM
- recognizable silhouette
- unique shape identity
- appealing proportions

2. SECONDARY FORMS
- layered details
- support shapes
- structure breakup
- visual interest

3. TERTIARY DETAILS
- seams
- wood cuts
- screws
- stitching
- toy surface details
- tiny imperfections
- decorative carvings

==================================================
OBJECTS MUST NEVER LOOK:
==================================================

- mathematically generated
- perfectly symmetrical
- smooth and empty
- geometry-only
- procedurally primitive

==================================================
OBJECT SILHOUETTE RULES
==================================================

Each object needs:
- unique silhouette
- asymmetrical detail
- readable shape language
- visual charm

Examples:
BAD:
- cube bookshelf
- cylinder tree
- sphere fruit
- capsule character

GOOD:
- bookshelf with curved wood framing
- tree with layered leaf clusters
- fruit with dents and stylized stem
- character with layered costume parts

==================================================
MATERIAL BREAKUP RULES
==================================================

Every object surface must contain:
- texture variation
- edge highlights
- soft painted gradients
- subtle wear
- material separation
- layered shading

NO:
- flat colors
- default materials
- smooth plastic look
