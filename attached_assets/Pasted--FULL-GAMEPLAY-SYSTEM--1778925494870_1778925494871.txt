==================================================
FULL GAMEPLAY SYSTEM
==================================================

This is NOT a static AR viewer.

This is a FULLY INTERACTIVE EDUCATIONAL GAME.

The player must constantly:
- touch
- drag
- rotate
- match
- count
- explore
- solve
- build
- discover
- receive feedback

The game must feel:
- playful
- rewarding
- emotionally engaging
- interactive every few seconds

==================================================
CORE GAMEPLAY LOOP
==================================================

LOOP:
1. Vimo introduces challenge
2. Child explores scene
3. Child interacts with AR objects
4. System gives immediate feedback
5. Reward animation plays
6. Child progresses
7. Scene difficulty increases slightly
8. Celebration moment
9. Unlock next activity

The player should NEVER feel idle.

Every 3–5 seconds:
- something animates
- reacts
- sparkles
- moves
- responds

==================================================
CHILD PSYCHOLOGY DESIGN
==================================================

The experience must be designed specifically for children age 5–8.

RULES:
- low frustration
- immediate feedback
- forgiving interactions
- emotional encouragement
- visual rewards
- audio reinforcement
- simple readable goals
- tactile interactions

Never punish harshly.

Wrong answers should:
- gently guide
- encourage retry
- provide hints
- animate softly

==================================================
FEEDBACK SYSTEM
==================================================

CORRECT ANSWER:
- stars explode
- sparkle particles
- happy sound
- Vimo celebrates
- object bounces
- glowing effect

WRONG ANSWER:
- soft wobble
- gentle sound
- hint appears
- encouraging voice line

NO harsh failure screens.
